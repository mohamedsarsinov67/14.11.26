# Объекты в JavaScript

Объект хранит несколько связанных значений под именами. Например, у игрового персонажа есть имя, здоровье и список предметов. Их можно собрать в одной переменной. Примеры можно запускать по очереди в консоли браузера или в теге `<script>`.

## 1. Создаём объект и читаем свойства

```js
const hero = {
  name: 'Лина',
  health: 80,
  hasKey: false,
  inventory: ['фонарь', 'верёвка'],
};

console.log(hero.name);          // Лина
console.log(hero.health);        // 80
console.log(hero.inventory[0]);  // фонарь
```

Объект записываем в фигурных скобках. `name` — ключ, то есть имя свойства. `'Лина'` — его значение. Между ключом и значением ставим двоеточие, а свойства разделяем запятыми. Значениями могут быть строки, числа, `true` и `false`, массивы и другие объекты.

В `hero.name` точка отделяет имя переменной от имени свойства. В `hero.inventory[0]` сначала получаем массив из свойства `inventory`, затем берём его первый элемент.

## 2. Отсутствующие свойства, `null` и `delete`

### Что получим, если свойства нет

Создадим персонажа с именем и прочитаем свойство `weapon`.

```js
const scout = { name: 'Мира' };

console.log(scout.weapon); // undefined
```

При чтении отсутствующего свойства JavaScript возвращает `undefined`. В этом примере у `scout` есть только свойство `name`.

### Когда используют `null`

`null` можно записать в свойство явно. Например, мы хотим хранить информацию об оружии, и сейчас у Миры его нет.

```js
scout.weapon = null;

console.log(scout.weapon); // null
console.log(scout);        // { name: 'Мира', weapon: null }
```

В первом примере свойства `weapon` нет, и чтение даёт `undefined`. Во втором свойство уже есть, и его значение — `null`.

### Как удалить свойство

Оператор `delete` удаляет указанное свойство из объекта целиком. Если прочитать это свойство снова, получим `undefined`.

```js
delete scout.weapon;

console.log(scout.weapon); // undefined
console.log(scout);        // { name: 'Мира' }
```

### Как менять и добавлять свойства

Выполните эти строки после примера с `hero`.

```js
hero.health = 100;             // Меняем существующее свойство.
hero.level = 2;                // Добавляем новое свойство.
hero.inventory.push('ключ');   // Добавляем предмет в массив внутри объекта.
hero.hasKey = true;
```

`const` позволяет менять свойства объекта. При этом переменная `hero` продолжает ссылаться на тот же объект.

## 3. Читаем свойство через квадратные скобки

```js
console.log(hero['name']); // Лина

const property = 'health';
console.log(hero[property]); // 100 после предыдущего примера
```

`hero.name` и `hero['name']` читают одно и то же свойство. Скобки пригодятся, если имя свойства хранится в переменной. В примере `hero[property]` подставляет значение переменной `'health'` и читает `hero.health`.

## 4. Кладём объект внутрь объекта

Свойство тоже может хранить объект. Например, у заказа есть адрес доставки с городом и улицей.

```js
const order = {
  number: 12,
  address: { city: 'Тюмень', street: 'Лесная' },
};

console.log(order.address.city); // Тюмень
```

Сначала `order.address` даёт объект с адресом, затем `.city` читает город из этого объекта.

## 5. Храним несколько объектов в массиве

Каждый элемент массива `books` — отдельная книга с названием и количеством страниц. По индексу выбираем книгу, а через точку читаем её свойство.

```js
const books = [
  { title: 'Остров сокровищ', pages: 240 },
  { title: 'Маленький принц', pages: 96 },
];

console.log(books[0].title); // Остров сокровищ

books.forEach((book) => {
  console.log(book.title + ' — ' + book.pages + ' стр.');
});
```

Знакомые методы массива работают и здесь. Через `push()` можно добавить целую книгу, а через `splice()` — удалить её по индексу.

## Практика

Каждое задание можно выполнить отдельно. Выводите результаты через `console.log()`.

### 1. Продажа товара

Создайте объект `product` со свойствами `title`, `price` и `stock`. Название товара — «Блокнот», цена — `150` рублей, остаток — `4` штуки.

Напишите функцию `sell(quantity)`. Если товара хватает, посчитайте стоимость покупки, уменьшите остаток и выведите стоимость и новый остаток. Если товара мало, сообщите об этом.

Сначала вызовите `sell(3)`. Покупка стоит `450` рублей, на складе остаётся `1` блокнот. Затем вызовите `sell(2)`. Продажа должна быть отклонена, а остаток после обеих попыток должен равняться `1`.

### 2. Расходы за день

Создайте массив `expenses`. Каждая покупка — объект с названием `title`, категорией `category` и суммой `amount`.

| Покупка | Категория | Сумма |
| --- | --- | ---: |
| Обед | еда | 350 |
| Автобус | транспорт | 45 |
| Хлеб | еда | 80 |

Запишите категорию `'еда'` в переменную. Через `forEach()` найдите покупки этой категории и сложите их суммы в переменной, которая изначально равна `0`. Выведите итог после перебора. Для еды должно получиться `430` рублей. Поменяйте категорию на `'транспорт'` и запустите код снова. Теперь итог должен быть `45` рублей.
